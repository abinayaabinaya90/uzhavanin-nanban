Uzhavanin Nanban (உழவனின் நண்பன்) — Farmer's Friend
About

Uzhavanin Nanban is an agri-tech web app designed to support Indian farmers and urban terrace gardeners with smart, AI-driven crop tools. It brings together disease detection, weather forecasting, government scheme information, and a direct farmer-to-buyer marketplace into one accessible, bilingual (Tamil + English) platform.

The goal is to reduce dependency on middlemen, help farmers catch crop problems early, and make government support schemes easier to discover and apply for.

Features
🔍 Crop Disease Detection — Upload a photo of a plant to get an AI-powered diagnosis and treatment recommendations.
🌦️ Weather & Agro Alerts — Localized weather forecasts and rainfall alerts to help plan irrigation and harvesting.
🏛️ Government Schemes & Subsidies — Browse eligibility for schemes and subsidies based on landholding and crop type, and track application status.
🤖 AI Crop Management Assistant — A chat-based assistant offering personalized farming advice, with Tamil voice support.
🪴 Terrace Garden Plant Fit — Get AI suggestions for what crops fit a given balcony/terrace space, tailored for urban gardeners.
🛒 Farmer Direct Marketplace — List and sell produce directly to buyers with zero commission.

Getting Started

Clone the repo and install dependencies:

bash
git clone https://github.com/abinayaabinaya90/uzhavanin-nanban.git
cd uzhavanin-nanban
npm install
npm run dev

The app will run locally at http://localhost:5173 (or the port Vite assigns).

To build for production:

bash
npm run build
Project Status

This project is a work-in-progress prototype/demo. Some data (contact numbers, scheme details, application statuses) is currently placeholder content for demonstration purposes and should be replaced with verified, real information before any public launch.
